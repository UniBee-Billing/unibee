## Quick links for new developers

1. **Run UniBee locally** — [Quick start](guides/quick-start.md): clone → Docker Compose → open Admin Portal.
2. **Integrate with your app** — Follow the [Integration Workflow Guide](https://docs.unibee.dev/documentation/business-integration/integration-workflow) (sandbox, webhooks, checkout, customer portal).
3. **Call the API** — Use the [API Reference](https://docs.unibee.dev/api-reference) with your API key and any HTTP client (REST only; no language-specific SDKs).
